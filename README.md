# Smartnick Services Website

A professional website for Smartnick Services - painting and home improvement company.

## Features

- Responsive design
- Hero section with call-to-action
- Services showcase
- Customer testimonials
- Contact information section
- Built with React and Tailwind CSS

## Getting Started

### Installation

1. Clone the repository
```bash
git clone https://github.com/smartnick12/smartnick-services-website.git
cd smartnick-services-website
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

The website will open at http://localhost:3000

## Building for Production

```bash
npm run build
```

This creates an optimized production build in the `build` folder.

## Technologies Used

- React 18
- Tailwind CSS 3
- JavaScript ES6+
